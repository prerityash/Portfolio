# Soumya Prerit — Personal Portfolio

A minimalist, high-contrast developer portfolio inspired by the **Tomasz Gajda** Figma design. Built with clean, accessible, semantic HTML5, Vanilla CSS3, and modern JavaScript.

## 🚀 Live Preview & Quick Start

You can run this portfolio locally without any build tools, or using Vite:

### Option 1: Direct in Browser
Simply double-click `index.html` or open it in any web browser.

### Option 2: Using Vite Dev Server
```bash
npm install
npm run dev
```

### Option 3: Quick Local Server
```bash
npx serve .
```

---

## 🎨 Design System & Features

* **Diagonal Split Hero:** Signature high-contrast split hero separating introduction & developer profile card.
* **Boxed Headers:** Bold, uppercase section headers (`ABOUT ME`, `SKILLS`, `PORTFOLIO`, `CONTACT`) matching the Tomasz Gajda template.
* **Structured Skills Matrix:** Grouped into *Using Now*, *Learning & Exploring*, and *Other Skills & Languages*.
* **Minimalist Project Cards:** Clean, code-focused repository showcase displaying tech tags and direct GitHub links without clutter.
* **Direct Channels & Contact Form:** Direct links to LinkedIn, GitHub, email with one-click clipboard copy, and a functional contact form.
* **100% Responsive:** Seamlessly adapts across desktops, tablets, and mobile devices.

## 🛠️ Deploying to GitHub Pages

1. Commit and push your code to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/prerityash/portfolio.git
   git push -u origin main
   ```
2. In your GitHub repository settings, navigate to **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://prerityash.github.io/portfolio/` in a few minutes!
